# Amazon 商品 TikTok 热度分析

把与 ASIN 相关的 TikTok 视频候选样本整理成可用于决策的信号报告。触发本 Skill 后，自动使用当前已连接且符合 KOLSprite 工具契约的 MCP，无需再询问用户是否调用。

## 兼容 MCP 路由

- SellerSpace 云雅统一 MCP 可用且已鉴权时，优先使用云雅。
- 支持业务工具直接调用，以及云雅当前版和旧版两种门面入口。
- 直接模式下，按语义业务名称识别并调用 `asin_analysis_video`。
- 云雅门面模式下，如果宿主顶层看不到业务工具，最多进行一次宿主级发现，并优先使用产品专属入口 `yunya_search_kolsprite_tools`。用 ASIN 视频分析意图查询一次；取得真实内部工具名及完整输入 Schema 后，再通过 `call_read_tool` 调用。
- 如果产品专属入口不可用、但可发现旧版通用入口 `yunya__search_tools`，则使用 provider `kolsprite`、operation `read` 和相同意图调用。产品专属入口可用时，不应优先使用通用入口。
- 不得猜测门面命名空间、内部工具名、包装结构或参数；本次任务复用已发现的名称和 Schema。
- 宿主顶层没有命中 `asin_analysis_video`，不代表内部业务工具不存在。只有直接模式以及可用的当前版或旧版门面查询都失败后，才能报告业务依赖缺失。两个门面入口都无法发现时，应明确报告连接器发现失败，不得切换到无关替代服务。
- 独立 KOLSprite MCP 仅在所需语义工具名、输入结构和返回结构一致时兼容。
- 如果两种连接同时启用，本次任务全程只使用一个连接，优先云雅，不得在两个服务之间重复执行付费调用。
- 如果缺少 `asin_analysis_video` 或其结构不兼容，按下文要求将其视为依赖缺失并停止。

## 输入要求

- 需要一个或多个 Amazon ASIN，以及 `US`、`GB` 等 Amazon 站点。
- 除非用户另行指定，TikTok `region` 默认与 Amazon 站点一致。
- 当宿主产品或用户提供 Amazon 标题、叶子类目、品牌、核心功能和关键属性时，应使用这些信息提高相关性判断；不得编造缺失的 Listing 信息。
- ASIN 和所有 TikTok ID 均按字符串处理。

## 选择一种模式

- **快速检查：** 用户提供一个 ASIN 并询问是否有 TikTok 热度或信号时默认使用。请求第 1 页、20 条记录，报告头部内容热度、证据质量、扩散情况、商业信号和代表性证据。
- **完整信号：** 用户要求完整或深入分析、整体热度、近月对比，或询问信号为何上升或下降时使用。最多请求第 1–5 页，每页 20 条；结果已取完或发生实质错误时提前停止。将采集到的高播放视频视为代表性头部样本，只能对最近 30 天相较前 30 天做粗略整体判断。
- **ASIN 对比：** 用户提供 2–3 个 ASIN 或明确询问哪个商品的 TikTok 机会更强时使用。所有 ASIN 必须采用相同市场、地区、模式、分页大小、相关性规则和计算规则。除非用户明确要求完整对比，否则默认快速检查。

一次任务不要自动分析超过 3 个 ASIN。每个 ASIN 都需要独立的分页调用链；其中一条失败时，应报告其余已完成的部分对比结果。

## 获取并标准化 MCP 证据

1. 调用 `asin_analysis_video`，传入 `asin`、`market`、`region`、`page_num` 和 `page_size: 20`。
2. 解析 MCP 结果中的文本 JSON，同时兼容旧版数组响应和分页响应：

   ```text
   list = Array.isArray(data) ? data : data?.list ?? []
   ```

3. 保留 `pageNum`、`pageSize`、`total`、请求页数、返回行数、去重行数和停止原因。
4. 按 `id` 对视频去重。如发现稳定 ID 页面疑似重复，应停止采集，不得宣称获得了更多覆盖。
5. 将每条视频分类为 `same_product_family`、`highly_similar`、`related_scene` 或 `noise`。计算或判断前先阅读 [statistics-and-judgment.md](references/statistics-and-judgment.md)。
6. 所有热度、动量、扩散和商业计算中，`same_product_family` 与 `highly_similar` 权重相同；排除 `related_scene` 和 `noise`，但保留其数量用于披露证据质量。

统一工具契约预期返回近约六个月发布的视频，按播放量降序排列，并以每页 20 条分页。应把它视为当前集成预期，而不是永久协议事实；如果当前 MCP 元数据或返回记录与其冲突，应披露实际观察边界并缩小判断范围。

## 判断与解释

- 分开呈现 **MCP 观察**、**客户端计算**、**粗略业务判断** 和 **建议动作**。
- 完整信号模式在代表性样本足够支持时，可以表述“整体近 30 天热度较上一个 30 天上升、持平或混合、下降（粗略）”。方向判断应综合有效视频活跃度、达人扩散和按视频年龄校正后的播放速度，并展示这些基础数值，不得暗示存在精确预测分数。
- 近月对比应使用发布批次和按视频年龄校正后的播放速度，不能只比较累计播放量，因为较早发布的视频有更长的播放累积时间。
- `salesVolumeLst30d` 是当前滚动 30 天数值，不得描述为视频发布月份产生的历史销量。
- MCP 的 `total` 是服务端候选总数，不是有效同款或相似视频数量。
- 不得声称 TikTok 导致 Amazon 销量变化、TikTok 商品就是该 Amazon ASIN，或本 Skill 可以预测未来销量。
- 输出完整信号或 ASIN 对比前阅读 [output-contract.md](references/output-contract.md)。快速检查可以只使用其中的精简模板，无需加载完整对比说明。

## 证据与停止规则

- 有效的同商品家族或高度相似视频少于 3 条时，判定为 **可靠信号不足**。可以展示最佳证据和排除项，但不得强行给出热度等级。
- 最近 30 天与前 30 天两个批次合计有效视频少于 3 条时，无法进行近月对比。样本较少或只集中在一个批次时，只能给出明确标注的粗略观察，不得给出正式趋势等级。
- 遇到鉴权、权限、点数不足、限流、结构错误或重复服务错误时，停止受影响的调用链。不得更换凭证或隐瞒采集中断。
- 如果当前统一 MCP 工具列表中没有 `asin_analysis_video`，应报告所需工具不可用并停止，不得用 `video_search` 替代，也不得编造 ASIN 映射。
- 不得获取超出所选模式的额外页面。将快速对比扩展为完整对比会显著增加成本或等待时间时，必须先询问用户。
- 点数消耗以实际执行的 MCP 调用为准。不得写死点数价格；只有 MCP 或宿主返回实际消耗时才能报告。失败、空结果或证据不足不等于账号一定被扣费。

## 以一个下一步决策收尾

先给出热度和动量判断，再展示证据。最后根据不同信号给出一个行动，例如优先验证某个 ASIN、测试多位达人、复用已验证的内容角度，或因当前证据较弱而暂停。完成 ASIN 决策后，更广泛的 TikTok 商品、视频、字幕或达人研究应作为可选后续步骤。

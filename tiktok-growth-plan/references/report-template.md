# TikTok Growth Plan Report Pattern

Use only sections that support the decision, but keep the result and first actions before detailed evidence.

## 1. Positioning, entry decision, and confidence

- Primary business goal:
- Recommended positioning/path:
- Category decision: prioritize validation / conditional entry / not recommended now / unable to determine.
- Overall confidence and decision-changing gaps.

## 2. Three immediate actions

| Priority | Action | Path | Dependency/owner | Metric | Review/stop condition | Evidence |
|---|---|---|---|---|---|---|

## 3. Upstream evidence scope

Summarize the account-audit and category-research ledgers, periods, markets, samples, completeness, and compatibility exclusions.

For a reusable or partner-facing run, apply the shared [run evidence display](../../tiktok-shop-growth-research/references/evidence-display.md). A completed plan is workflow execution evidence, not a measured business outcome.

## 4. Account × category gap matrix

Use the workflow matrix and label reusable asset, capability gap, blocking risk, or test needed.

|---|---|---|---|---|---|
